# Hotel Reservation System ## Complete Hotel Management Solution for Odoo 17 This module provides a comprehensive hotel reservation management system with the following features: ### Key Features #### 🏨 Room Management - Create and manage hotel rooms - Define room types (Single, Double, Suite) - Set pricing per night - Track room capacity and status - Monitor room availability in real-time #### 👥 Client Management - Store client information securely - Email and phone validation - Track passport numbers - View client reservation history - Smart buttons for quick access to related data #### 📅 Reservation Management - Create and manage reservations - Automatic price calculation based on stay duration - Prevent overlapping reservations - Multiple status workflows (Draft, Confirmed, Cancelled) - Automatic room status updates - Calendar view for easy visualization - Smart conflict detection #### 🌐 Web Portal - Public booking interface - Available rooms display - Online reservation form - Automatic confirmation page - Mobile-responsive design #### 🔄 API Synchronization - Integration with Booking.com - Integration with Airbnb - Automatic reservation import - Availability synchronization - Scheduled hourly updates via CRON jobs #### 📊 Reporting & Analytics - Reservation statistics - Pivot table analysis - Revenue graphs - Occupancy reports - Client analytics ### Technical Highlights - **Odoo Version**: 17.0 - **License**: LGPL-3 - **Dependencies**: base, mail, portal, web - **Architecture**: MVC pattern with full Odoo integration - **Security**: Role-based access control - **Performance**: Optimized queries and indexed fields - **Testing**: Comprehensive unit test suite included ### Installation 1. Copy the module to your Odoo addons directory 2. Update the apps list 3. Install "Hotel Reservation System" 4. Configure API keys for external integrations (optional) ### Configuration Navigate to Settings → Technical → System Parameters to configure: - Booking.com API credentials - Airbnb API credentials - Synchronization intervals ### Usage Access the module from the main menu: - **Rooms**: Manage hotel rooms and availability - **Clients**: Track customer information - **Reservations**: Create and manage bookings - **Configuration**: Set up API integrations ### Web Access Customers can make reservations directly at: - `/hotel/reservation/form` - Booking form - `/hotel/rooms` - Available rooms list ### Support For support, customization, or questions, contact your Odoo partner or administrator. --- **Developed with ❤️ for the hospitality industry**
